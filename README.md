**PhonePe Transactions Dashboard**
An interactive dashboard built to analyze PhonePe transaction data.  
It provides insights into total transactions, successful and failed payments, service-wise transaction amounts, monthly trends, and failure reasons.

Tools Used
- Power BI
- Data Analytics
- Excel / CSV

## Key Highlights
- Date range filtering
- Transaction success vs failure analysis
- Service-wise and monthly trend visualization
- Failed payment reason breakdown

This project is created for data analysis and visualization purposes.
